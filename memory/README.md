# Persistent Agent Memory (Project Scope)

This directory contains structured, indexed memory for AI coding sessions.

## Categories
- `patterns/`: Proven solution patterns and workflows that succeeded.
- `anti-patterns/`: Tricky bugs, gotchas, and failure modes to avoid.
- `rules/`: Concrete operational constraints and repository guidelines.
- `decisions/`: Architecture Decision Records and technical choices.

Managed via `atk memory` and `manage_memory.py`.
